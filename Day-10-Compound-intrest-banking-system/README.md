## Day 03 — 📧 Random Email ID Generator

A simple Python project that generates a random Gmail-style email ID using the user's name and a randomly generated number.

### 🚀 How It Works

1. The program asks the user to enter their name.
2. A random number between 10 and 999 is generated.
3. The name and random number are combined.
4. A Gmail-style ID is displayed.

* Inheritance

* `super()`

* User input
* f-strings

# Day 10 — 💰 Compound Interest Banking System

A Python-based **Compound Interest Banking System** that simulates common banking operations while also calculating compound interest on the account balance.

This project combines **Object-Oriented Programming, mathematical calculations, transaction management, user input, and date/time handling** to create a more advanced version of a basic banking system.

### 🚀 Features

* 🏦 Create a Savings or Current Account
* 👤 Store account holder information
* 🔢 Generate a random account number
* 💰 Deposit money
* 💸 Withdraw money
* 💵 Check current balance
* 📊 Calculate compound interest
* 📈 Support different compounding frequencies
* 🧾 Maintain transaction history
* 🕒 Record transaction date and time
* 🔄 Interactive banking menu

### 📐 Compound Interest Formula

The project uses the standard compound interest formula:

```text
A = P(1 + r/n)^(nt)
```

Where:

```text
P = Principal Amount
r = Annual Interest Rate
n = Number of times interest is compounded per year
t = Time in years
A = Final Amount
```

### 💻 Example

```text
========== COMPOUND INTEREST ==========

Principal Amount : ₹10000.00
Interest Rate    : 10%
Time             : 2 years
Compounds/Year   : 1

Interest Earned  : ₹2100.00
Final Amount     : ₹12100.00
```
