## Day 03 — 📧 Random Email ID Generator

A simple Python project that generates a random Gmail-style email ID using the user's name and a randomly generated number.

### 🚀 How It Works

1. The program asks the user to enter their name.
2. A random number between 10 and 999 is generated.
3. The name and random number are combined.
4. A Gmail-style ID is displayed.

### 🧠 Concepts Used

* Python Classes
* Inheritance
* `__init__()` constructor
* `super()`
* `randint()` from the `random` module
* User input
* f-strings

### 💻 Example

```text
Enter your name: shri

Your mail id is shri527@gmail.com
```

### 🎯 Learning Goal

This project was created to practice Python OOP concepts, especially inheritance and the use of `super()`.

# Day 08 — 🏏 IPL Performance & Match Prediction

A Python-based **IPL Performance & Match Prediction System** that stores team statistics, player performance, and uses historical team performance to predict the winner between two teams.

The project focuses on using **nested dictionaries, user input, OOP, and basic mathematical calculations** to build a simple cricket analytics system.

### 🚀 Features

* 🏏 Add multiple IPL teams
* 📊 Store matches played by each team
* 🏆 Store matches won
* ❌ Calculate and store matches lost
* 📈 Calculate team win percentage
* 🔮 Predict a winner between two teams
* 👤 Add individual player performance
* 🏏 Store player runs
* ⚡ Store player strike rate
* 🎯 Store player wickets
* 🔍 Search and display player performance
* 📊 Calculate an estimated next-match score using stored performance data

### 🗂️ Data Structure

The project uses a **nested dictionary** to organize team and player information.

Example:

```python
{
    "MI": {
        "played": 10,
        "won": 7,
        "lost": 3,
        "players": {
            "Rohit Sharma": {
                "runs": 450,
                "strike-rate": 145.5,
                "wickets": 0
            }
        }
    }
}
```

This structure allows multiple teams and multiple players to be stored within the same program.

### 📈 Match Prediction

The current prediction system calculates the team's win percentage using:

```text
Win Rate = (Matches Won / Matches Played) × 100
```

The team with the higher win rate is selected as the predicted winner.

### 🧠 Concepts Practiced

* Object-Oriented Programming
* Classes and inheritance
* Dictionaries
* Nested dictionaries
* Functions and methods
* User input
* `if-elif-else`
* `while` loops
* Mathematical calculations
* String formatting
* Type conversion
* Data organization
* Basic performance analysis

### 🎯 Learning Goal

This project helped me understand how real-world information can be represented using **nested data structures**.

It also helped me practice connecting:

## Day 09 — 🏆 College Sports Registration System

A console-based **Sports Event Registration Portal** built in Python that validates student credentials (PRN and Roll Number) before allowing team entries across multiple inter-college sports categories.

The program uses classes, conditional validation ranges, and nested dictionary structures to dynamically collect rosters and register squads based on player quotas for each sport.

### 🚀 Features

* 🔐 Two-factor credential validation using allowed ranges for PRN and Roll Number
* 🏅 Multi-sport category support:
  * 🏏 Cricket (11 Players)
  * 🤼‍♂️ Kabaddi (8 Players)
  * 🏃🏻‍♂️ Kho-Kho (10 Players)
  * 🏐 Volleyball (7 Players)
* 📋 Captures custom team name, captain name, and full player rosters
* 🗃️ Stores roster data mapped to team names via dictionaries
* 🛡️ Input validation with case-insensitive category matching (`.lower()`)

### 🗂️ Data Structure

Each sport maintains a dedicated dictionary mapping the registered team name to a roster list:

```python
teamc = {
    "Warriors XI": [
        "Captain Name",
        "Player 2",
        "Player 3",
        # ... up to full squad size
    ]
}
🧠 Concepts Practiced
Python OOP (class definition, instance instantiation, and method invocation)

Range checks via chained comparisons (min_val < input < max_val)

Nested control flow (if-elif-else branches)

Dictionaries with list values

String methods (.lower())

Dynamic CLI prompts and formatted f-strings

▶️ How to Run
