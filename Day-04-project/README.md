\## ## Day 02 — 🎮 Rock Paper Scissors



A Python-based \*\*Rock Paper Scissors game\*\* where the player competes against a computer-controlled opponent.



The computer randomly selects Rock, Paper, or Scissors, while the player enters their choice. The program compares both choices and determines whether the player wins, loses, or gets a draw.



\### 🎯 Features



\* 🎮 Play Rock Paper Scissors against the computer

\* 🤖 Computer makes a random choice

\* 🔄 Option to play multiple rounds

\* 📝 Saves the game result to a text file

\* 🧠 Uses dictionaries to map user choices

\* 🔢 Uses numerical values internally to compare choices



\### 🧠 Concepts Practiced



\* Python functions

\* `random.choice()`

\* Dictionaries

\* User input

\* Conditional statements

\* `while` loops

\* File handling

\* `with open()`

\* String formatting

\* Basic game logic



\### ▶️ How to Run



Run the Python file from the terminal:



```bash

python game.py

```



Then enter:



```text

r → Rock

p → Paper

s → Scissors

```



Example:



```text

enter your choice: r



you chose rock

computer chose paper



you won

```



The player can continue playing by entering `y` when asked:



```text

you wanna play again(y/n): y

```

```text

├── game.py

├── result.txt

└── README.md

```



\### 💡 What I Learned



This project helped me understand how randomness, dictionaries, functions, loops, conditions, and file handling can be combined to create an interactive Python program.

\## Day 03 — # 📧 Random Email ID Generator

A simple Python project that generates a random Gmail-style email ID using the user's name and a randomly generated number.

## 🚀 How It Works

1. The program asks the user to enter their name.
2. A random number between 10 and 999 is generated.
3. The name and random number are combined.
4. A Gmail-style ID is displayed.

## 🧠 Concepts Used

* Python Classes
* Inheritance
* `__init__()` constructor
* `super()`
* `randint()` from the `random` module
* User input
* f-strings

## 💻 Example

```text
Enter your name: shri
Your mail id is shri527@gmail.com
```

## 📂 File

* `email_generator.py` — Main Python program

## 🎯 Learning Goal

This project was created to practice Python OOP concepts, especially inheritance and the use of `super()`.

## 🔮 Future Improvements

* Generate different email domains
* Prevent duplicate IDs
* Save generated IDs to a file
* Add a GUI
* Generate multiple IDs at once
